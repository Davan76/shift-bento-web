# 輪班便當（網頁版）v1.98

以 12 天循環為基礎的輪班班表網頁。

## 功能

- 第一頁:輸入工號進入。
- 第二頁:班表(顯示全部組員,姓名遮罩顯示;自己的那一列會標示)。
- 組員可以在「我的排休」點選日期,排休日會以黃色底色標示。
- 上班格無底色,休假格與排休格保留顏色。

## 檔案

- `index.html`:第一頁(工號輸入)。
- `schedule.html`:第二頁(班表與排休)。網頁本身不含班表;登入後以工號向後端驗證,才讀取班表。

## 注意

- 班表一律以 Excel 為準:Excel「匯出班表」產生 .xlsx(班表＋排休兩個工作表),管理者在網頁「管理 → 匯入班表」匯入後,組員即可看到;不需要重新產生網頁。
- 排休資料由後端 Cloudflare Worker 保存。
